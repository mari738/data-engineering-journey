* Testing unique values

* Testing CHECK conditions

### Key Learning

Constraints help maintain data integrity by controlling what kind of data can be stored in a table.

A primary key uniquely identifies a record, while a composite primary key uses multiple columns together to uniquely identify a record.

A foreign key creates a relationship between tables and helps ensure that related data exists in the referenced table.
